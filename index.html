CHD password

The blotter, the research list and the research price list are open to everyone with the link. Only the CHD view and the Zanibal CSV need the CHD password. The CHD list is only published encrypted with it.

Once someone enters it, that computer stays unlocked in that browser for 30 days, or until the password is changed. Another computer or browser asks again.

To change the password (IT):

  1. On GitHub, open the private repository price-list-generator-src → Settings → Secrets and variables → Actions.
  2. Edit DOWNLOAD_PASSWORD_ZANIBAL and save the new password (8 characters or more).
  3. In the same repository, open Actions → Update download passwords → Run workflow. The new password works about 2 minutes later, and the old one stops.
  4. Give the new password to people by phone or Teams, not by email.
